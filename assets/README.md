## Refresh behavior

`.github/workflows/koi.yml` runs daily at 00:20 UTC. `.github/workflows/snake.yml` runs daily at 00:35 UTC. Both also support manual dispatch and run when their generation inputs change. They share a concurrency group and use only the built-in `GITHUB_TOKEN`, with `contents: write` confined to the publishing jobs. Actions are pinned to inspected commit SHAs.

Both generators write to temporary directories and validate their complete output before replacing committed assets. A failed run leaves the last good assets in the repository. Commit steps stage only their own generated files, skip unchanged output, and use ordinary pushes after rebasing onto `main`.

The README provides still images for reduced-motion browsers, and the generated SVGs also honor reduced motion internally. No essential profile information depends on animation. GitHub's own contribution section is controlled by GitHub; the README adds an animated graph above that native section.

GitHub can pause scheduled workflows in public repositories after 60 days without activity. The last generated assets remain visible; re-enable the workflow in Actions if needed.
