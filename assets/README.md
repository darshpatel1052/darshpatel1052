- `hero/blackhole.gif` is generated by [TerminalTextEffects](https://github.com/ChrisBuilds/terminaltexteffects) 0.15.0's built-in **Blackhole** effect. [pyfiglet](https://github.com/pwaller/pyfiglet) 1.0.4 supplies the ANSI Shadow lettering; Pillow rasterizes the engine's cells into a looping GIF. The motion is the existing tool's effect. `scripts/render-hero.py` records the configuration and fixed seed. Install `scripts/hero-requirements.txt` to regenerate it. The hosted page loaded on 2026-11-02, but its catalogue API was unreachable, so the profile links the project source.

- `koi/` is generated from **darshpatel1052's public data** by [git-koi](https://github.com/yalongwastaken/git-koi), an MIT-licensed project. No other account's output is used.
- `widgets/` contains unmodified output from [GitHub Profile Summary Cards](https://github.com/vn7n24fzkq/github-profile-summary-cards), [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg), and [Skill Icons](https://github.com/tandpfun/skill-icons). ## Refresh behavior

`.github/workflows/koi.yml` runs daily at 00:20 UTC. `.github/workflows/snake.yml` runs daily at 00:35 UTC. Both also support manual dispatch and run when their generation inputs change. They share a concurrency group and use only the built-in `GITHUB_TOKEN`, with `contents: write` confined to the publishing jobs. Actions are pinned to inspected commit SHAs.

Both generators write to temporary directories and validate their complete output before replacing committed assets. A failed run leaves the last good assets in the repository. Commit steps stage only their own generated files, skip unchanged output, and use ordinary pushes after rebasing onto `main`.

`.github/workflows/widgets.yml` refreshes statistics daily at 00:50 UTC and supports manual dispatch. It also runs when its script, workflow, or source URLs change. `scripts/fetch-widgets.py --stats-only` downloads and validates the complete statistics set before replacing any previous card. Service errors leave the last good cards intact. This workflow shares the same publishing concurrency group and uses only the built-in token to commit the downloaded public cards. Viewers do not need the external services to be online. The quote animation and Skill Icons grid are fixed content and are not downloaded every day.

The README provides still images for reduced-motion browsers, and the generated SVGs also honor reduced motion internally. No essential profile information depends on animation. GitHub's own contribution section is controlled by GitHub; the README adds an animated graph above that native section.

GitHub can pause scheduled workflows in public repositories after 60 days without activity. The last generated assets remain visible; re-enable the workflow in Actions if needed.

## GitHub's native contribution section

README content cannot remove or replace GitHub's own contribution graph and activity list. To hide them from visitors, open **Settings → Public profile → Contributions & Activity → Make profile private and hide activity → Update preferences**. [GitHub documents this setting](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/setting-your-profile-to-private). It also hides achievements, follower/following counts, organization memberships, and other social profile information. The README remains public. The account owner can still see their own activity while signed in; verify the visitor view while signed out. See [GitHub's private-profile reference](https://docs.github.com/en/account-and-profile/concepts/personal-profile#private-profiles). Public-data statistic services may have less contribution information available after this setting changes. No account privacy setting is changed by this repository.
